How to Play

Controls

  • Left-click / drag select units
  • Right-click move / attack / harvest / rally
  • Shift queue orders or add to selection
  • Ctrl+click / double-click select all of a type
  • A attack-move · S stop · H hold · P patrol · M move
  • B / V basic / advanced build (workers)
  • Ctrl+1-9 set group · 1-9 recall (double-tap to jump)
  • F1 idle worker · F2 select army · Space last alert
  • Arrows / screen edges / middle-drag scroll · Wheel zoom
  • F10 / Esc menu & pause

The war economy

Workers harvest Crystal and Flux. Build supply structures to grow your army. Each race upgrades its main base through three tiers. Higher tiers unlock advanced production, giant tier-3 units and higher upgrade levels.

Races

Vanguard Directorate: builders stay on site. Command Bastion → Citadel → Stronghold. Fusion Works unlocks Titans and Dreadnoughts.

Kyrrh Swarm: units hatch from larva; buildings need creep; Drovers give supply. Brood Nest → Sanctum → Throne. Great Cavern and Elder Aerie unlock Behemoths and Gravemaws.

Aethel Concord: shields regenerate; structures need a Lumen field. Sanctum Core → Radiant → Exalted. Celestial Archive unlocks Hierophants and Empyreans.

Destroy every enemy structure to win.
